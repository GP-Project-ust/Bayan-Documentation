%   1 الهوية والصلاحيات (8)  two rows
%   2 مصادر البيانات (4)      chain
%   3 العروض الذكية (5)       row A: views/versions/deps, row B: params/outputs
%   4 الفهرس الدلالي (6)      row A: terms/entries/links/embeddings
%   5 المستندات (3)           chain
%   6 التقارير (2)            chain
%   7 التدقيق (1)             wide box
% Long wiring:
%   - Tenants spine (right margin x=15.7) with taps; joins inside band 1.
%   - Actor spine (left margin x=0.35): audit -> memberships / users.
%   - entries->tenants on left margin (x=0.75) and top channel y=0.70.
%   - Security bridge smart_views.required_permission_id -> permissions
%     (kauaccent, right margin x=16.9) with callout; hops the top channels.
%   - saved_reports rises at x=11.45: branch to versions (x=11.05) and
%     left channel to memberships (y=3.90).
%   - saved_report_parameters rises at x=8.1 into parameters (compound
%     hop over the sr-main and feeder channels).
%   - entries and dependencies share a references bus (y=5.85) fanning to
%     the three source tables (junction dots mark the two feeders).
% Deliberate line-hops (semicircular jumps) mark the only crossings:
%   bridge x top channels (x=5.5), actor x bus ascent (x=11.1),
%   and srp-rise x (sr-main + feeder) channels (x=8.1).
